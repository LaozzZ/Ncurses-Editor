# Ncurses-Editor
基于C/C++与curses库实现的的终端⽂本编辑器  
Windows/Linux可用  
**本项目仅为学习而开发，并非实际投入日常使用的软件**
## 界面说明
* **书写区:** 终端上除最后一行的区域为书写区，光标输入的字符会出现在其上
* **状态栏:** 终端的最后一行为状态栏，状态栏会显示文件名，光标所处行、列，以及进行特殊操作时的提示信息
## 操作说明
* **基本输入:** 键入字符、`Space`或`Enter`即可将字符显示在终端上的光标后，同时移动光标
* **方向键:** 使用方向键即可移动光标，光标只能到达有字符的位置，光标不能移到终端显示区域之外
* **功能键:**
  * **退出键:** `Ctrl+Q` 即可退出程序，在某些特殊状态(如搜索中，替换中)时不能退出
  * **删除键:** `Backspace` 键删除光标前的第一个字符， `Delete` 键删除光标后的第一个字符
  * **保存键:** `Ctrl-S` 可以对目前已被修改的文档进行保存，文档已修改但未保存时，按下 `Ctrl-Q` 提示文件未保存，再次按下强制退出不保存。若文件处于被修改状态，状态栏的文件名会变为黄色，且文件名开头会多出 `*`
  * **搜索键:** `Ctrl-F` 进入搜索模式，此时可以输入字符串进行搜索，已键入的字符会显示在状态栏，按下 `Enter` 进行搜索，之后再次按 `Enter` 可以切换下一个候选， `Esc` 退出搜索模式。搜索时可以随时按 `Backspace` 修改待搜索的文本，之后再次按 `Enter` 即可继续搜索
  * **替换键:** `Ctrl-R` 进入替换模式，同样可以在状态栏输入字符串，按 `Enter` 进行搜索，之后再次输入字符串作为替代文本，输入后再次按 `Enter` 进入替换模式，此时按 `Enter/N` 可切换候选,按 `Y` 替换当前候选并移动至下一候选处，按 `A` 替换全部候选，按 `Esc` 退出替换模式。需要注意的是，进入替换模式后就无法修改搜索文本和替代文本，需要退出并重新进入替换模式
  * **撤回键:** `Ctrl-Z` 即可撤回上一步操作，最多可以存储20步已进行的操作
* **终端尺寸修改:** 当你修改终端尺寸或修改字体大小时，程序会自动适配并保证光标处在视口范围内
* **文件读取:** 可以通过命令⾏参数打开⼀个指定的⽂本⽂件：`./dedit <filename>` 并进行修改，如果打开错误，则会输出错误信息。未读取文件时，会默认文件名default.txt，此时保存会在终端的路径下生成文件
## 已知问题/局限
* 程序无法兼容中文输入、含有中文文本的文件，如果输入会产生大大小小的问题导致程序无法正常使用
* 终端尺寸修改的瞬间，终端上显示的文本会出现瞬间跳动的问题，但是在尺寸修改结束后便会恢复。这个问题的成因是Windows的终端在尺寸改变时会自动对其中的文本进行适配，而这个适配处在程序的适配之前，且无法阻断，因而产生文本跳动问题，并非程序自身的问题，而是因为程序基于Windows终端运行而产生的局限
